= multimedia-rpc

Media jobs as a gRPC service backed by ffmpeg, ImageMagick and GStreamer:
typed operations, async workers, object storage.

== Service

`mmrpc.v1.MediaJobService`, ordered by what a caller needs first.

[cols="1,3"]
|===
|Method |Use case

|`CreateJob` |Submit a job; idempotent on `idempotency_key`, optional callback queue.
|`GetJob` |Read state, progress and result by job id.
|`WatchJob` |Stream state and progress until the job reaches a terminal state.
|`ListJobs` |Page one owner's jobs, filtered by state.
|`CancelJob` |Cancel a pending or running job.
|===

`mmrpc.videomerge.v1.VideoMergeService` serves the merge reference's job
shape over the same store: `CreateJob`, `GetJob`, `CancelJob`,
`ListUserJobs`, with a requester, ordered input files and an output
profile on every job.

Operations (`OpSpec` oneof): `probe` inspect, `transcode`, `trim`,
`thumbnail`, `concat`, `image` resize/convert/composite, `package` HLS,
`ladder` ordered renditions and a master playlist.
Results are object-storage keys; no media bytes cross the API.

== Example

[source,sh]
----
MM_BIND_ADDR=127.0.0.1:50051 mmrpcd combined

grpcurl -plaintext \
  -import-path proto -proto mmrpc/v1/service.proto \
  -d '{"idempotencyKey":"demo-1","spec":{"probe":{"input":{"objectUri":"s3://mm/demo.mp4"}}}}' \
  127.0.0.1:50051 mmrpc.v1.MediaJobService/CreateJob
----

`mmrpcd combined` needs `MM_DATABASE_URL` and `MM_OBJECTSTORE_*`. When
`MM_AUTH_JWKS_FILE`/`MM_AUTH_ISSUER` are set, add
`-H 'authorization: Bearer <token>'`.

== Crates
- mmrpcd — daemon: server, worker, combined
- mm-domain — ids, job state machine, op catalog, ports
- mm-proto — v1 contract and conversions
- mm-jobstore — migrations, the job repository, shared input metadata
- mm-worker — claim loop, op pipelines, callbacks
- mm-ffmpeg — probe, progress, process supervision
- mm-magick — identify and convert argv, parsing, runner
- mm-gst — pipeline description, bus parsing, packaging runner
- mm-server — gRPC service, auth interceptor, health
- mm-storage — object store and callback queue adapters
- mm-auth — bearer token verification
- mm-observability — metrics registry, scrape endpoint, records
- mm-testkit — shared test harness
- mm-integration — live integration suite

ImageMagick, GStreamer, node and buf, at the versions `flake.lock` holds.

cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --all --check
sh scripts/parity.sh
sh scripts/auth-conformance.sh

sh scripts/duration-conformance.sh
sh scripts/stability.sh
